## Cómo leer este sitio

- Este sitio presenta entregables finales del curso, organizados por prácticas y proyectos.
- Cada sección muestra documentación, evidencias y archivos fuente asociados a cada entrega.
- Los módulos agrupan resultados de simulación, diseño PCB, montaje y validación.
- La navegación está pensada para revisión técnica rápida por tema o por tipo de evidencia.
- Para visualizar el sitio localmente: `pnpm dev`.
