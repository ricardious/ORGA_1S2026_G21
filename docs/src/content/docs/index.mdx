## Cómo leer este sitio

- Este sitio presenta entregables finales del curso, organizados por prácticas y proyectos.
- Cada sección concentra la documentación técnica y los resultados principales de cada entrega.
- La navegación está pensada para revisión rápida del contenido que sí forma parte de las entregas.
- Para visualizar el sitio localmente: `pnpm dev`.
