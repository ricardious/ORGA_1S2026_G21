# PCB y esquemáticos

Sección para estandarizar documentación de diseño electrónico y fabricación.

## Qué incluir

- Esquemático eléctrico final.
- Decisiones de layout y ruteo.
- Reglas de diseño (ancho de pista, clearances, capas).
- Exportación de gerbers y archivos de fabricación.
- Evidencias de montaje y pruebas eléctricas.

## Recomendaciones de etiquetado

- Revisiones: `pcb_revA`, `pcb_revB`.
- Archivos gerber con fecha: `gerbers_YYYY-MM-DD.zip`.
- Fotos: `pcb_top`, `pcb_bottom`, `pcb_montada`.

## Entregables y evidencias

- Archivos de diseño PCB: `pcb/`
- Gerbers y BOM: `pcb/fabricacion/`
- Esquemáticos: `diagramas/`
- Evidencias de placa fabricada: `evidencias/pcb/`
