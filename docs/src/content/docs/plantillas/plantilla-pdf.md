# Plantilla de documento PDF final

## Secciones sugeridas

1. Portada (curso, equipo, fecha).
2. Objetivo.
3. Requisitos.
4. Entradas y salidas.
5. Diseño lógico/electrónico.
6. Implementación (simulación, montaje y/o PCB).
7. Pruebas y resultados.
8. Evidencias.
9. Presupuesto.
10. Conclusiones.
11. Referencias.

## Recomendaciones de formato

- Índice automático.
- Figuras y tablas numeradas.
- Capturas legibles con pie de figura.

## Entregables y evidencias

- PDF final: `docs-pdf/`
- Fuentes de figuras/tablas: `diagramas/`, `simulacion/`, `evidencias/`
- Anexos técnicos: `pcb/`, `presupuesto/`
- Versiones intermedias: `docs-pdf/borradores/`
