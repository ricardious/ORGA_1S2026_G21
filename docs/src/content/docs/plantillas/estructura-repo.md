# Estructura recomendada del repo

```text
practicas/
  practica-N/
    docs-pdf/
    simulacion/
    montaje/
    diagramas/
    pcb/
    presupuesto/

proyectos/
  proyecto-N/
    docs-pdf/
    simulacion/
    montaje/
    diagramas/
    pcb/
    presupuesto/

evidencias/
  capturas/
  fotos/
  videos/
  pruebas/
```

## Criterios

- Una carpeta por práctica/proyecto.
- Archivos fuente separados de entregables finales.
- Evidencias centralizadas y también por módulo cuando convenga.

## Entregables y evidencias

- Estructura principal: `practicas/`, `proyectos/`, `evidencias/`
- Informe final: `*/docs-pdf/`
- Archivos de ingeniería: `*/diagramas/`, `*/simulacion/`, `*/pcb/`
- Costos: `*/presupuesto/`
