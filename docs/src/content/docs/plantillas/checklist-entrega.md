# Checklist universal de entrega

- Objetivo y alcance definidos.
- Requisitos documentados.
- Diseño lógico/electrónico incluido.
- Implementación registrada (simulación, montaje o PCB).
- Pruebas con resultados y criterios de aceptación.
- Evidencias anexadas y nombradas correctamente.
- Presupuesto actualizado con fuentes.
- Conclusiones y trabajo pendiente.
- Rutas del repo indicadas.

## Entregables y evidencias

- Checklist aplicado: `plantillas/checklists-completados/`
- Informe y anexos: `docs-pdf/`
- Evidencias multimedia: `evidencias/`
- Fuentes y diseño: `diagramas/`, `simulacion/`, `pcb/`
