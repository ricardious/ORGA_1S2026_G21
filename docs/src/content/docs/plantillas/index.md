# Plantillas

Usa estas plantillas para mantener uniformidad de documentación en todo el curso.

## Plantillas disponibles

- [Checklist de entrega](/plantillas/checklist-entrega/)
- [Estructura recomendada del repo](/plantillas/estructura-repo/)
- [Plantilla PDF final](/plantillas/plantilla-pdf/)

## Uso recomendado

- Copiar la plantilla al iniciar cada práctica/proyecto.
- Completar secciones mínimas obligatorias.
- Adjuntar rutas y evidencias desde el inicio.

## Entregables y evidencias

- Plantillas base: `plantillas/`
- Checklists completados: `plantillas/checklists-completados/`
- Versiones usadas por módulo: `practicas/*/` y `proyectos/*/`
- PDF final basado en plantilla: `docs-pdf/`
