# Presupuestos

Esta sección unifica el formato de costos para prácticas y proyectos.

## Plantilla base

- Lista de materiales.
- Cantidad por componente.
- Precio unitario.
- Subtotal por línea.
- Total general.
- Observaciones de disponibilidad.

## Recomendaciones

- Guardar al menos dos fuentes cuando sea posible.
- Registrar fecha de cotización.
- Diferenciar costo estimado vs costo real.

## Entregables y evidencias

- Tabla de presupuesto: `presupuesto/`
- Cotizaciones (PDF/capturas): `presupuesto/cotizaciones/`
- Facturas o comprobantes: `presupuesto/comprobantes/`
- Resumen en informe: `docs-pdf/`
