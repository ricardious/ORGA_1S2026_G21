# Plantilla de simulación en Proteus

Usa esta plantilla para estandarizar el reporte de simulaciones.

## Objetivo

Describir el comportamiento que se desea validar con la simulación.

## Esquema

- Bloques y componentes principales.
- Parámetros configurados.
- Supuestos de diseño.

## Pruebas

- Caso 1: condición de entrada, salida esperada y resultado.
- Caso 2: condición de entrada, salida esperada y resultado.
- Caso n: condición de borde.

## Archivo final

- Nombre de proyecto final.
- Versión.
- Fecha de cierre.

## Observaciones

Riesgos, limitaciones y ajustes pendientes.

## Entregables y evidencias

- Proyecto Proteus final: `simulacion/` o `simulaciones/`
- Capturas de prueba: `evidencias/simulaciones/`
- Tabla de casos: `docs-pdf/`
- Archivos auxiliares: `diagramas/`
