# Estructura estándar para evidencias

```text
evidencias/
  capturas/
  fotos/
  videos/
  pruebas/
```

## Reglas sugeridas

- Separar por módulo, práctica o proyecto.
- Mantener subcarpetas por fecha cuando aplique.
- Agregar archivo `README.md` breve en carpetas críticas.

## Ejemplo por práctica

```text
practicas/practica-1/
  montaje/
  simulacion/
  evidencias/
    capturas/
    fotos/
    videos/
    pruebas/
```

## Entregables y evidencias

- Estructura raíz de evidencias: `evidencias/`
- Evidencias por práctica/proyecto: `*/evidencias/`
- Registro de pruebas: `*/montaje/pruebas/`
- Soporte visual: `*/evidencias/fotos/` y `*/evidencias/videos/`
